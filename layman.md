# AWS AI Governance & Compliance Lab
**Domain:** Finance / Loan Processing  
**Goal:** Implement automated PII discovery and data immutability using the NIST AI RMF framework.

---

## Project Implementation: Step-by-Step

### Part 1: The Detective Phase (Macie & IAM)
In this first stage, we built a "Digital Auditor" system to find hidden privacy risks in financial datasets.

1. **Build the Vault (S3):** Created a secure storage bucket (`compliance-lab-sindhu-2026`) and uploaded financial data suspected of containing sensitive PII.
2. **Assign the Auditor (IAM):** Created a specific "Auditor-User" using AWS IAM. Following the **Principle of Least Privilege**, this user was granted only the specific "Read" permissions required for auditing—nothing more.
3. **Start the Scan (Macie):** Deployed **Amazon Macie** to act as a digital detective. When standard AI filters missed the sample data, I engineered a **Custom Data Identifier (Regex)** to specifically hunt for Social Security Numbers.
4. **The Finding:** The scan successfully triggered a **High Severity Finding**, proving the system can catch compliance leaks automatically before they become a liability.

### Part 2: The Protection Phase (Bucket Policy)
Once the risks were identified, I implemented a technical "Lock" to ensure the data remained safe and immutable.

1. **Identify the Loophole:** Realized that even with an auditor, data could still be deleted by accident or by a rogue user to cover up a breach.
2. **Write the Governance Rule (JSON):** Wrote a custom **S3 Bucket Policy** using a "Global Deny" statement. This told the AWS cloud: *"Regardless of who is asking, nobody is allowed to delete files from this vault."*
3. **Deploy the Guardrail:** Applied this JSON policy to the bucket permissions, acting as a permanent lock on the filing cabinet.
4. **Verify the Defense:** Attempted a manual deletion of a file. The system immediately blocked the action with an **"Access Denied"** error, confirming the governance rule is active and the data is protected.

## Framework Alignment (NIST AI RMF)
- **GOVERN:** Established accountability through IAM user tracking and bucket-level policies.
- **MEASURE:** Used Macie to quantify the volume of sensitive data (PII) within the environment.
- **MANAGE:** Created automated guardrails to prevent unauthorized deletion of audit-ready data.
